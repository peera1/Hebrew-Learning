# Hebrew Learning

אתר משחקים ופעילויות ללימוד עברית לילדים.

## מבנה הפרויקט

- `index.html` - דף הבית והניווט הראשי
- `GanHova/` - פעילויות לגן חובה
- `Class-a/` - פעילויות לכיתה א
- `Class-C/` - קבצים ומשאבים לכיתה ג
- `images/` - תמונות המשמשות את הפעילויות

## הפעלה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. עבור בדיקת נתיבים מלאה, מומלץ להפעיל שרת סטטי מתוך תיקיית הפרויקט, לדוגמה:

```text
python -m http.server 8000
```

לאחר מכן לפתוח את `http://localhost:8000`.

## פרסום ב-GitHub Pages

הפרויקט הוא אתר סטטי ללא שלב build. אפשר לפרסם את המאגר דרך GitHub Pages עם תיקיית המקור של הענף הראשי.
